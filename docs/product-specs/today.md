# 当日待办

## 目的

「当日待办（Today）」是用户每天规划与执行的核心作战大盘。它将宏观的「项目战役时间线」与微观的「每日四象限待办、日常习惯打卡、每日复盘」进行高效聚合，为用户提供一屏掌控当日所有精力分配的沉浸式工作台。

---

## 任务大盘与类型筛选

- **今日排期过滤与四象限分组**：
  - 自动筛选截止或排期覆盖今日（`today`）的有效任务；
  - 严格按四象限（🔥 紧急讨伐 `Q1` / 🌿 核心修炼 `Q2` / ⚡ 突发委托 `Q3` / 💧 支线见闻 `Q4`）分组呈现；
  - 未完成任务优先靠前展示，已完成任务沉底并带有完成样式。
- **任务类型快捷筛选胶囊（Filter Pills）**：
  - **「全部」**（默认）：全景展示今日所有到期任务（项目阶段任务 + 独立日常待办），确保全天工作不漏项；
  - **「仅项目」**：一键过滤出所有关联项目与阶段的攻坚任务，并展示实时计数徽章，适合进入深度工作（Deep Work）冲刺；
  - **「仅独立」**：一键过滤出日常琐事、生活杂务与单点待办，适合碎片时间快速清空。
- **任务项标识与微交互**：
  - 属于项目的任务展示 `[项目名 · 阶段名]` 微型公会标签；
  - 点击复选框就地打勾完成并触发即时音效与状态结算；
  - 点击任务行唤起全功能快捷编辑弹窗（`TaskQuickEdit`）；
  - 逾期任务呈现醒目的逾期时间标签（支持 Hover 快捷一键延期至今日）。

---

## 日常习惯修行与每日复盘

- **每日修行（习惯打卡）**：
  - 展示今日待打卡习惯与连续坚持天数（Streak）；
  - 点击「打卡」按键就地完成，已打卡项呈现翡翠勾选徽章；
- **冒险日志（每日复盘）**：
  - 展示当日复盘刻印状态；
  - 点击「前往 ➔」快捷跳转至 `/daily-review` 页面；
- **全通关清空画卷**：
  - 当日全部任务、习惯与复盘全部达成时，界面呈现通关画卷（`🏆 ⚔️ 今日委托已全数通关！经验值与金币已结算`）。

## 项目时间线（甘特图）与任务 4 维深度联动

当日待办底部的「项目推进时间线（`ProjectTimeline`）」采用与项目中心单体甘特图一致的专业左右分栏架构：
- **看板外左上角标题与今日命中统计**：左上角采用与上方待办列表对齐的外置层级规范（`[ 🟢 / 📜 ] 项目推进时间线` + `X 项任务` 精准计算当天命中的任务数）；
- **专业控制顶栏**：左侧收纳「周期翻页导航（`<` `日期区间` `>` `今天`）+ 项目筛选下拉（`全部项目 ▼`）」，右侧收纳「视图刻度切换器（`周视图` / `双周视图` / `月视图`）」；
- **表头永久置顶与单一滚动条架构**：
  - **表头置顶固定（Pinned Headers）**：左侧树状表头（`项目与阶段 / 进度`）与右侧时间轴日期表头整体置于可滚动 Body 外部，纵向向下滚动时表头始终稳固置顶可见；
  - **单滚动条驱动（Unified Scroll Engine）**：左侧树状容器使用 `overflow-hidden` 彻底清除冗余滚动条，右侧时间轴轨道承载唯一的垂直与横向滚动条，滚动时 1:1 驱动左侧内容垂直平移与顶部日期表头横向平移，左侧滑动滚轮自动转发右侧滚动；
- **左右 1:1 同步树状甘特结构**：
  - **全部项目模式**：呈现 `项目 ➔ 阶段 ➔ 任务` 三级树，项目与阶段均支持折叠展开，阶段展开后直接展示具体任务项与打卡复选框；
  - **单项目筛选模式**：自动扁平化呈现 `阶段 ➔ 任务` 二级树；
  - **垂直滚动严格同步**：左侧树状列表与右侧时间轴轨道高度 100% 像素级对齐；
- **时间视窗智能交集过滤与真实排期感知**：
  - **视窗交集动态过滤（Time-Window Intersection Filter）**：在“全部项目”视图中，自动过滤完全不在当前视窗周期的阶段与项目，彻底清除大面积空白无效行；
  - **真实排期感知**：阶段未设置排期且无任务时间时，真实保持未排期（`undefined`），绝不伪造虚假排期条，悬浮提示明确标注 `未排期`；单项目视图下完整保留阶段树并支持就地安排排期。

时间线与上方任务建立起确定性的 4 维双向协同体系：

### 1. 维度一：时间线 ➔ 任务详情与排期穿透（宏观到微观）
- **单击阶段条 / 阶段行**：触发内联**折叠 / 展开**，在左侧树状中就地查看、勾选完成或点击唤起 `TaskQuickEdit` 快速编辑任务，在右侧直观观察任务排期条；
- **Hover 阶段条 / 项目条**：显示轻量悬浮提示（Tooltip），快速查看所属项目、排期周期、完成率与任务数，无任何弹窗遮挡焦点；
- **单点截止任务日内精准比例呈现**：单点截止任务（如 `8.18 12:00`）规范为 `8.18 00:00 ➔ 8.18 12:00`，在当日网格内占据对应比例（如 50% 宽度），物理限制在当天网格内部，绝不跨天溢出；
- **双击阶段条 / 项目行**：直接触发全局路由导航跳转至 `/projects`，并在项目中心左侧自动选中该项目、阶段看板自动定位到该阶段。

### 2. 维度二：今日任务 ➔ 时间线定位联动（微观到宏观）
- 鼠标悬停在上方任务列表中带有项目标签的任务项时，下方时间线中对应的阶段与任务整行呈现**柔和的背景底色轻微过渡（`bg-muted/40`）**，时间条本身不叠加任何生硬边框高亮，零闪烁、纯净舒适；
- 悬停普通独立琐事待办（无 `projectId`）时，时间线保持沉静自然，无多余视觉噪音；
- 鼠标悬停在下方阶段或任务条时，上方任务列表中的同阶段任务亦同步高亮响应。

### 3. 维度三：实时双向进度同频
- 无论在今日待办、阶段浮层还是项目中心打勾完成任务，底层同一条 `time_management_tasks` 数据通过 React Query 缓存与 Broadcast 同频驱动；
- 时间线阶段条上的进度徽章（如 `✓ 3/5`）与填充底色实时推进，全部完成时触发翡翠光泽。

### 4. 维度四：时间线上快捷排期与新建联动
- 在时间线阶段行的某个日期格子上点击，自动唤起任务编辑弹窗，预填所属项目（`projectId`）、阶段（`projectStageId`）以及点击所在日期的起止时间段，大幅缩短任务规划路径。
