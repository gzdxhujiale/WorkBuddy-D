# 知识库与笔记

## 1. 目的与产品模型

知识库模块是面向用户的结构化笔记与个人知识沉淀工作区，支持层级化的容器组织、富文本笔记编辑、模板化复用以及多格式批量导入导出。

### 层级结构

知识库模块由四层结构组成：
1. **知识库 (`Folder`)**：顶层分类容器，用于对不同领域或主题（如“工作”、“学习”、“归档”）进行大类组织。
2. **文件夹 / 清单 (`List`)**：具体知识主题的收纳单元，可独立存在或从属于某一知识库。
3. **笔记分组 (`NoteGroup`)**：清单内部的可视化逻辑分组，支持就地创建、重命名、删除及折叠。
4. **笔记 (`Note`)**：实际内容载体，包含标题、基于 Tiptap JSON 的富文本正文及更新时间戳。

## 2. 交互与组织方式

### 统一拖拽调度 (`@dnd-kit`)
知识库模块完全通过 `@dnd-kit` 统一调度拖拽交互，提供直观的桌面端直接操作体验：
- **清单与知识库排布**：支持在左侧侧边栏内上下拖拽调整顺序，或将独立清单拖入知识库进行归属分组。
- **跨清单移动笔记**：将笔记条目直接拖拽至侧边栏的目标清单或知识库，即完成跨清单归档。
- **分组内与跨组排序**：将笔记在清单内上下拖拽以调整次序，或拖入指定分组区域进行归类。

### 下拉菜单与原子操作
- 笔记条目与抽屉菜单采用统一收敛的 `DropdownMenu` 组件，专注于提供「创建副本」、「删除」等高频原子动作。
- 笔记的移动操作全量交由拖拽交互承载，不设置冗余的多层级子菜单与搜索选择框。

### 统一弹窗体系 (`Modal`)
- 知识库模块的所有弹窗交互（如添加/编辑知识库、新建文件夹、批量导出、模板库等）均统一接入基于 `@arco-design/web-react` 的标准弹窗组件（`src/components/ui/modal.tsx`），保持设计系统的严谨与桌面端视觉一致性。

### 极简属性与排序
- 知识库、文件夹与笔记不维护 `icon`（图标）、`color`（颜色主题）、`viewType`（视图模式）以及 `isPinned`（置顶）等冗余或未生效状态。
- 列表排序遵循清晰的单一规则：按自定义排序权重（`sortOrder`）升序排列，同权重的笔记按最后更新时间（`updatedAt`）倒序展示。

## 3. 加载与性能规范

- **Shell-First 分步加载**：进入模块时仅加载左侧侧边栏知识库树与清单基本元数据（`loadAll`）；点击选中清单后再拉取该清单下的分组列表与笔记摘要（`loadListContents`）；点击打开笔记时按需获取完整富文本正文（`loadNote`）。
- **编辑防抖与清理持久化**：笔记正文编辑通过防抖定时自动保存；当抽屉关闭或组件卸载时，自动触发最新脏数据立即写入，确保编辑内容不丢失。
- **跨端与离线排队**：支持通过 `runOrQueue` 在离线状态下保留操作指令并在网络恢复后回放；跨窗口/多端通过 Supabase 私有 Broadcast 发送窄粒度失效通知并重新拉取。
