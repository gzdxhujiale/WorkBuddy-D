# 项目中心

## 目的

项目是一个完整需求或事项的生命周期容器。项目中心不会维护第二份任务数据：项目任务就是任务中心的 `time_management_tasks`，只额外关联一个项目和一个可选流程阶段。

## 项目属性与多级智能排序

- 项目具有名称、说明、可选开始/结束日期、负责人、优先级和标签；日期表示项目时间段，而非单一截止日期。
- 项目状态固定为“未开始、进行中、已完成、已归档”。新建项目始终从“未开始”开始；流程的自定义性由阶段而非项目状态承担，避免两套状态混淆。
- 进度按未删除的项目任务完成率自动计算，不单独写入数据库。
- 仅当所有项目任务完成后，用户才能将项目手动标记为完成。数据库也会拒绝绕过界面的提前完成操作。
- **项目列表排序规则**：
  1. **第一优先级（项目优先级）**：严格按照项目优先级降序排列（🔥 紧急 `urgent` > 🌿 高 `high` > ⚡ 中 `medium` > 💧 低 `low`）；
  2. **第二优先级（完成进度）**：同优先级内按任务完成率（`已完成任务数 / 总任务数`）从高到低排列，推进迅速和收尾中的项目优先靠前；
  3. **第三优先级（更新时间）**：按 `updated_at` 降序兜底排列。

## 阶段看板、象限化交互与任务编辑

- **阶段象限卡片化看板**：
  - 每个阶段采用与任务中心四象限一致的卡片风格（支持主题色边框、背景渐变、序号徽章、阶段名称内联修改、任务计数徽章、阶段周期 `DateRangePicker` mini 以及头部折叠展开）；
  - 单列垂直流式布局，自适应高度并提供极佳的纵向排版体验；
  - 阶段看板右上角配备「+ 添加阶段」一键创建按钮。
- **任务时间状态折叠分组**：
  - 阶段内任务按「已过期 / 一天内 / 三天内 / 一周内 / 一周外 / 无日期」分组（`CollapsibleGroup`）折叠展示，并提供逾期一键延期至今日操作；
  - 任务项 Hover 背景变色与任务中心象限完全同步（现代主题与像素主题专属配色），并通过预置透明占位图标消除 Hover 出现删除按钮时的高度抖动。
- **任务编辑窗口无缝联动**：
  - 点击阶段内任务或阶段头部「+」按键唤起全功能任务编辑弹窗（`TaskQuickEdit`）；
  - 支持配置任务标题、富文本详情备注、单点截止时间、起止时间段（`scheduledStartAt` ~ `scheduledEndAt`）、提醒规则，以及通过弹窗右上角旗标直接切换任务优先级与所属象限。
- **阶段与任务生命周期**：
  - 新建项目任务可落入一个阶段，并默认使用该阶段负责人；任务的负责人可单独覆盖。
  - 项目可软删除；删除项目会在同一数据库事务内软删除其所有阶段和项目任务。阶段也可软删除；删除阶段会软删除其任务。已删除项目、阶段和任务不会出现在项目中心或任务中心的活动视图中。
  - 一个任务至多属于一个项目。它在项目中心与任务中心两处展示，标题、完成状态、排期和其他共享字段始终来自同一条任务记录。

## 模板

- 模板保存阶段、阶段默认负责人，以及待生成任务的标题、说明、优先级、负责人和所属阶段。
- 从模板创建项目会生成未开始的项目、阶段和未完成任务；不复制任务完成状态，也不复制具体任务日期。
- 空白项目可以之后新增阶段与任务。
- 项目模板在“设置 → 模板管理”中新增、编辑和软删除；已删除模板不会出现在创建项目的模板选择中。

## 实现约束

- `projects`、`project_stages`、`project_templates` 和任务关联均通过用户所有权、RLS 与受限 RPC 保护。
- 项目任务变更通过已有私有 Broadcast 通道发出无行数据的失效提示；任务中心和项目中心各自按窄查询键重新读取。
- 新阶段的排序由数据库事务分配，避免多个窗口或快速重复操作使用过期排序值而发生唯一键冲突；排序仅在未删除阶段内保持唯一，以便删除阶段后复用其位置。
