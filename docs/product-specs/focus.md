# 悬浮专注助手与专注记录

## 1. 目的与产品模型

专注助手（Focus Assistant）是 WorkBuddy-D 的轻量级桌面悬浮伴侣，旨在为用户提供无干扰、随手可控的沉浸式番茄钟/倒计时专注与休息管理工具，并融入桌宠伴侣趣味互动。

### 核心定位
- **独立二级窗口 (`focus-assistant.html`)**：轻量级 Webview 窗口，默认常驻屏幕并支持快捷置顶与无边框拖拽移动。
- **三维目标深度关联**：
  - 支持 **「项目」**、**「任务」**、**「习惯」** 三大 Tab 分类快速绑定，或选择「暂不关联目标」纯专注模式；
  - **项目树状选择器**：支持按 `项目 ➔ 阶段 ➔ 任务` 树状层级浏览与折叠展开，支持灵活关联整个项目、特定阶段或细分任务节点；
  - **独立任务过滤**：任务 Tab 自动过滤排除项目任务（保持与任务中心四象限纯粹待办一致）；
  - **一键数据刷新**：弹窗右上角提供旋转刷新按钮（`RotateCw`），无需关闭窗口即可即时并行同步最新的项目、任务与习惯。
- **全生命周期闭环**：专注时段 ➔ 自动双重对话通知 ➔ 自动休息时段 ➔ 休息结束通知 ➔ 恢复就绪，形成无缝工作流。

## 2. 交互与状态流转

### 专注与休息模式流转

| 状态 | 模式 (`sessionType`) | 视觉与特征 | 交互控制 |
| :--- | :--- | :--- | :--- |
| **就绪 (`ready`)** | `focus` | 经典/像素/矢量主题色彩，显示设定时长与待机伴侣 | 点击开始按钮开始专注；点击标题切换关联目标；点击时间调出设置弹窗；点击伴侣触发戳一戳互动 |
| **专注中 (`running`)** | `focus` | 环形/条形进度填充，伴侣呈现认真工作/敲键盘姿态，倒计时递减 | 点击暂停专注；点击右上角菜单或悬浮按钮可直接结束专注并进入休息 |
| **专注暂停 (`paused`)** | `focus` | 进度定格，伴侣呈现歪头发呆姿态，提供「继续」与「结束」按钮 | 点击继续恢复倒计时；点击结束立即触发系统通知并自动开始休息 |
| **休息中 (`running`)** | `rest` | 清新绿色主题（`stroke-emerald-500`），伴侣呈现喝茶/打瞌睡姿态，标题显示「☕ 休息时段」 | 点击暂停休息；点击选项菜单可「跳过休息 / 重新专注」 |
| **休息暂停 (`paused`)** | `rest` | 进度定格，提供「继续」与「跳过」按钮 | 点击继续恢复休息倒计时；点击跳过发送提示通知并复位到专注就绪态 |

### 时间配置规范
- **自定义范围**：
  - **专注时间**：支持 `1 ~ 180` 分钟任意整数（默认 25 分钟）。
  - **休息时间**：支持 `1 ~ 60` 分钟任意整数（默认 5 分钟）。
- **呼出方式**：
  - 在卡片模式或纯宠物模式下，直接点击大字号数字倒计时或头顶计时胶囊。
  - 在选项设置下拉菜单中，点击「修改时间设置」。
- **持久化策略**：专注与休息时长设定分别持久化存储至 LocalStorage（`workbuddy.focusAssistant.minutes` 与 `workbuddy.focusAssistant.restMinutes`）。

## 3. 多维度通知与多显示器覆盖系统

系统采用「悬浮窗内头顶对话气泡」、「全显示器同步角标 Toast」以及「Web Audio 多感官声音反馈」三重形态联动，彻底解决 Windows 原生通知在副屏/扩展屏不可见以及打包后静默被拦截的问题：

1. **全显示器同步角标 Toast (`NotificationToast`)**：
   - 阶段转换（专注完成/休息开始/休息结束）时，自动枚举所有物理连接的显示器（主屏 + 扩展屏 1 + 扩展屏 2...）；
   - 在各显示器右下角同步滑出独立置顶的毛玻璃/像素风通知卡片，显示伴侣动态头像、阶段大标题与 4.5 秒平滑递减进度条，倒计时完毕平滑滑出关闭；
   - 突破操作系统限制，确保用户视线无论停留在哪块屏幕均能 100% 获取提醒。
2. **多感官轻量声音反馈 (`soundFeedback.ts`)**：
   - 基于 Web Audio API 纯代码合成，无任何外部音频文件依赖，0 延迟、0 流量；
   - **专注完成音效**：现代风温润和弦钟声 / 像素风复古 8-bit Level-Up 通关琶音；
   - **休息结束音效**：清脆悦耳的清晨唤醒双音阶；
   - **戳一戳互动**：软萌交互反馈音；
   - 在选项菜单中提供「提示音效」一键开启/静音切换。
3. **悬浮窗内头顶气泡 (`SpeechBubble`)**：
   - 伴随淡入浮现动画，在角色上方呈现气泡，3.8 秒后自动淡出。
   - 点击气泡可立即关闭；点击伴侣（戳一戳）随时触发互动随机打气台词。
4. **系统桌面通知第一人称播报**（作为系统底层兜底）：
   - **猫咪伴侣**：标题 `🐱 专注伴侣`，第一人称猫猫语音（“喵！我们开始专注啦，我会一直陪着你的~”）。
   - **小狗伴侣**：标题 `🐶 专注伴侣`，第一人称汪汪语音（“汪！开始专注啦，狗狗会一直陪着你的 (U•ᴥ•U)🐾”）。
   - **专注完成**：“🎉 太棒啦！完成了专注，跟我一起休息 X 分钟放松一下吧~”
   - **休息结束**：“☕ 伸个大大的懒腰~ 休息结束啦，准备开始新的冲刺了吗？”

## 4. 视觉主题与桌宠动作体系

提供 7 种专属风格主题（支持随时在右键/设置菜单中切换）：
1. **经典浅色卡片 (`classic`)**：现代极简卡片，配备经典环形进度条与中心控制按钮。
2. **复古像素猫 (卡片) (`pixel`)**：8-bit 怀旧像素游戏风（VS Code Pets / Tamagotchi 质感），含像素动画猫咪伴侣、像素点阵倒计时与复古卡片。
3. **复古像素猫 (纯宠物) (`pixel-pure`)**：80px 像素猫咪桌面桌宠，头顶常态计时胶囊，悬停下方浮现操作条，拖拽灵动迈步。
4. **复古像素狗 (卡片) (`pixel-dog`)**：8-bit 怀旧像素小狗伴侣（金黄毛色、红色项圈、小金铃铛、打字与摇尾巴动效）。
5. **复古像素狗 (纯宠物) (`pixel-dog-pure`)**：80px 像素小狗桌面桌宠，悬停操作栏，拖拽四肢向前走动。
6. **现代矢量柴犬 (卡片) (`vector`)**：生动细腻的现代矢量卡通伴侣（眨眼、打字、咖啡热气、爱心），配合柔和渐变卡片。
7. **现代矢量柴犬 (纯宠物) (`vector-pure`)**：纯透明柴犬桌宠，支持头顶倒计时、悬停下方微型操作条与右键呼出菜单。

- **就地动作与全周期状态流转**：
  - **专注中 (`working`)**：伴侣认真打字/敲键盘，外置笔记本屏幕发光动效；
  - **休息中 (`resting`)**：伴侣抱热茶咖啡杯或打瞌睡冒出浮动 `z Z`；
  - **专注完成庆祝 (`celebrating`)**：伴侣双爪高举欢呼跳跃、开心笑眼 `^^`，头顶浮升金色 `+EXP ✨` 徽章与闪烁星光，悬浮窗外框亮起金色呼吸辉光（4.5秒）；
  - **休息结束提醒 (`stretching_knocking`)**：伴侣先向前压低伸懒腰（1.5秒），随后连续敲击下方桌面/敲屏幕（2.5秒）提醒用户就绪。
- **拖拽与走步动效规范**：
  - **按住拖拽**：即时响应鼠标移动方向（向右拖动面向右侧迈步走动，向左拖动面向左侧迈步走动）。
  - **悬停与静止**：单纯鼠标悬停 Hover、点击戳一戳保持自然稳定姿态，绝不产生误翻身。
- **窗口尺寸自适应**：
  - 纯宠物模式：`220 x 180 px`（居中透明，对话气泡最大宽度 200px 永不遮挡）
  - 默认卡片模式：`205 x 80 px`
  - 展开统计面板：`205 x 145 px`
  - 时间设置弹窗：`210 x 190 px`
  - 关联目标选择弹窗：`210 x 290 px`
  - 选项与主题菜单：`210 x 260 px`
  - 全屏幕角标 Toast 弹窗：`320 x 88 px`

## 5. 数据库持久化与数据隔离

- **记录隔离与存储**：所有的专注与休息通过 `focus_sessions` 表持久化：
  - `type` 为 `'focus' | 'rest'`。
  - `cycle_id` 将同一个工作周期内的专注记录与休息记录关联成环。
  - `active_seconds` 精确记录实际有效时长。
- **统计纯净性**：今日/本周专注统计（`focusAssistantApi.getFocusStats`）严格按 `type = 'focus'` 进行过滤统计，休息时段不计入专注时长。
- **异常关闭处理**：当应用退出或窗口意外关闭时，自动将当前正在进行中的未闭合会话标记为 `interrupted`，防止脏数据滞留。
