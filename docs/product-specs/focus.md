# 悬浮专注助手与专注记录

## 1. 目的与产品模型

专注助手（Focus Assistant）是 WorkBuddy-D 的轻量级桌面悬浮伴侣，旨在为用户提供无干扰、随手可控的沉浸式番茄钟/倒计时专注与休息管理工具。

### 核心定位
- **独立二级窗口 (`focus-assistant.html`)**：轻量级 Webview 窗口，默认常驻屏幕并支持快捷置顶与无边框拖拽移动。
- **目标关联**：支持快速绑定当前待办任务（Task）、日常打卡习惯（Habit）或纯专注无关联模式。
- **全生命周期闭环**：专注时段 ➔ 自动系统通知 ➔ 自动休息时段 ➔ 休息结束通知 ➔ 恢复就绪，形成无缝工作流。

---

## 2. 交互与状态流转

### 专注与休息模式流转

| 状态 | 模式 (`sessionType`) | 视觉与特征 | 交互控制 |
| :--- | :--- | :--- | :--- |
| **就绪 (`ready`)** | `focus` | 经典主题色彩，中心蓝色播放图标，显示设定时长 | 点击中心按钮开始专注；点击标题切换关联目标；点击时间调出设置弹窗 |
| **专注中 (`running`)** | `focus` | 蓝色环形进度条顺时针填充，倒计时递减 | 点击暂停专注；点击右上角菜单可直接结束专注并进入休息 |
| **专注暂停 (`paused`)** | `focus` | 进度环定格，中心提供「继续」与「结束」按钮 | 点击继续恢复倒计时；点击结束立即触发系统通知并自动开始休息 |
| **休息中 (`running`)** | `rest` | 清新绿色环形进度条（`stroke-emerald-500`），标题显示「☕ 休息时段」 | 点击暂停休息；点击选项菜单可「跳过休息 / 重新专注」 |
| **休息暂停 (`paused`)** | `rest` | 进度环定格，中心提供「继续」与「跳过」按钮 | 点击继续恢复休息倒计时；点击跳过发送提示通知并复位到专注就绪态 |

### 时间配置规范
- **自定义范围**：
  - **专注时间**：支持 `1 ~ 180` 分钟任意整数（默认 25 分钟）。
  - **休息时间**：支持 `1 ~ 60` 分钟任意整数（默认 5 分钟）。
- **呼出方式**：在专注态或休息态下，点击主界面上的大字号数字倒计时均可唤起「时间设置」弹窗。
- **持久化策略**：专注与休息时长设定分别持久化存储至 LocalStorage（`workbuddy.focusAssistant.minutes` 与 `workbuddy.focusAssistant.restMinutes`）。

### 系统桌面通知机制
通过 Tauri 原生通知插件（`@tauri-apps/plugin-notification`，并带 Web Notification 容错降级）触发全系统弹窗通知：
1. **专注结束**：
   - *自动完成*：倒计时归零时触发 `🎉 恭喜！已完成「xxx」时段，开始 X 分钟休息放松一下吧！`
   - *手动结束*：提前结束时触发 `本次专注已结束，开始 X 分钟休息时段。`
2. **休息结束**：
   - 休息倒计时归零时触发 `☕ X 分钟休息时段已结束，准备好开始新的专注了吗？`
3. **跳过休息**：
   - 手动跳过休息时触发 `已跳过休息：休息时段已跳过，已恢复专注就绪状态。`

## 3. 视觉主题与辅助能力

- **多套视觉主题**：提供经典浅色（Light）、暗黑夜色（Dark）、毛玻璃透明（Glass）及极简纯色（Minimal）4 种外观。
- **窗口尺寸自适应**：
  - 默认紧凑模式：`200 x 75 px`
  - 展开统计面板：`200 x 140 px`
  - 时间设置弹窗：`200 x 180 px`
  - 关联目标选择弹窗：`200 x 280 px`
  - 选项与主题菜单：`200 x 210 px`
- **置顶与拖拽**：默认窗口置顶（`setAlwaysOnTop`），点击无控件区域直接调用原生窗口拖拽（`startDragging`）。

---

## 4. 数据库持久化与数据隔离

- **记录隔离与存储**：所有的专注与休息通过 `focus_sessions` 表持久化：
  - `type` 为 `'focus' | 'rest'`。
  - `cycle_id` 将同一个工作周期内的专注记录与休息记录关联成环。
  - `active_seconds` 精确记录实际有效时长。
- **统计纯净性**：今日/本周专注统计（`focusAssistantApi.getFocusStats`）严格按 `type = 'focus'` 进行过滤统计，休息时段不计入专注时长。
- **异常关闭处理**：当应用退出或窗口意外关闭时，自动将当前正在进行中的未闭合会话标记为 `interrupted`，防止脏数据滞留。
