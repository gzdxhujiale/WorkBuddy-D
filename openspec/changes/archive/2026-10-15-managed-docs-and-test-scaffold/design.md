# Design: Managed Architecture Docs Synchronization & Go Backend Automated Test Scaffolding

## 1. Documentation Alignment Matrix

### 1.1 `AGENTS.md`
- **Project**: Update technology baseline to Tauri 2, React 19, Tailwind CSS 4, Go 1.23+ standalone server, Neon PostgreSQL, Goose migrations, pgx/v5 pool, `log/slog`, and WebSocket Realtime. Remove Arco Design.
- **Operating Invariants**: Preserve affirmative action rules (差分作用域验证, 最小因果改动, 事实锚定, 数据所有权, 分层访问).
- **Commands**: Add Go backend commands (`go -C server test ./...`, `go -C server build ./cmd/server`), Tauri commands, and document validation commands.

### 1.2 `ARCHITECTURE.md`
- **System Topology**:
  - `Desktop Native Layer`: Tauri 2 (`src-tauri/`) with `single-instance`, `window-state`, `global-shortcut`, `autostart`, and `notification`.
  - `Frontend Webview Layer`: Multi-window React 19 SPA (`src/`) communicating via HTTP/REST and WebSocket to Go backend.
  - `Standalone Application Server`: Go 1.23+ HTTP/WS server (`server/`) with Chi/Mux router, JWT auth middleware, note write buffer, and WebSocket Hub.
  - `Database Layer`: PostgreSQL (Neon / local) managed by embedded Goose migrations (`server/internal/database/migrations/`) and typed queries generated by `sqlc`.

### 1.3 `docs/BACKEND.md`
- **Baseline & Runtime**: Document Go 1.23+ server, pgxpool connection management, Goose embedded versioned migrations, and `log/slog`.
- **Package & Layering**: Clarify `server/cmd/server/`, `server/internal/handler/`, `server/internal/buffer/`, `server/internal/ws/`, `server/internal/database/`.
- **Concurrency & Reliability**: Document `NoteBufferManager` periodic flushes and graceful shutdown drain, and WebSocket broadcast invalidation.

### 1.4 `docs/FRONTEND.md`
- **Component UI**: Replaced Arco Design with bespoke Tailwind CSS 4 UI primitives (`src/components/ui/`).
- **Bundle Partition**: Document `react-vendor`, `tanstack-vendor`, and `tiptap-vendor` chunk partitioning.

## 2. Go Backend Automated Test Architecture

### 2.1 Config Test (`server/internal/config/config_test.go`)
- Test environment variable parsing and fallback defaults for `Port`, `DBDSN`, `JWTSecret`, `CORSOrigin`.
- Test quote stripping and empty lines in `.env` parser.

### 2.2 Buffer Test (`server/internal/buffer/note_buffer_test.go`)
- Mock `sqlc.Querier` for `PatchNote`.
- Verify `BufferPatch` marks item dirty and updates memory cache.
- Verify `FlushDirty` dispatches batch updates to database queries and clears dirty flags.
- Verify thread safety under concurrent writes.
