# Proposal: 今日工作台智能逾期任务收敛与就地极速规划 (Today Tasks Overdue & Quick Plan)

## Why

目前 WorkBuddy-D 存在两项核心工作流割裂问题：
1. **历史逾期任务被静默隐藏**：今日工作台仅计算严格与今天日期相交的任务，昨天或历史截止但未打勾完成的任务在今日工作台中完全不可见，导致任务被遗忘，必须去任务中心或项目中心反复翻找；
2. **今日规划与创建流程割裂**：用户在「今日工作台」准备开启一天的工作时，缺少直接创建任务的入口，必须跳出到任务中心或项目中心去新建任务，打断了工作心流。

本变更旨在让「今日工作台」升级为真正的日规划与执行指挥中心：自动召回历史未完成的逾期任务并提供一键延期/完成操作，同时在今日工作台内嵌回车即建的极速录入栏。

## What Changes

- **智能逾期任务（Overdue Tasks）自动召回**：
  - 修改今日任务计算逻辑：今日待办集 = 「排期在今日的任务」 + 「所有未完成且截止时间早于今天的逾期任务」。
  - 在今日工作台时间流 / 四象限顶部醒目展示「⚠️ 逾期未结」分组及数量徽章。
  - 为逾期任务提供一键快捷操作：`📅 顺延至今日`（更新截止时间为今日 23:59）与 `✓ 勾选完成`。
- **今日就地极速录入栏（Inline Quick Add）**：
  - 在今日工作台顶部提供常驻极速录入栏，输入标题后按 `Enter` 立即创建并插入今日任务流。
  - 自动默认设置排期为“今天”，并支持快捷切换四象限（🔥紧急讨伐、🌿核心修炼、⚡突发委托、💧支线见闻）。
  - 支持在录入时快捷关联所属项目（可选）。

## Capabilities

### New Capabilities
- `today-workbench`: 包含今日工作台任务集定义（今日排期 + 历史逾期未完结任务）、逾期任务一键顺延操作契约，以及今日就地极速任务创建交互规范。

## Impact

- **受影响的前端组件与模块**：
  - `src/lib/taskSchedule.ts`：增加/扩展任务逾期判定与今日任务集组合逻辑。
  - `src/components/today/TodayPanel.tsx`：增加极速录入组件（Inline Quick Add）、逾期任务展示分组与一键顺延交互。
  - `src/types/timeManagement.ts` / `src/hooks/useTimeManagement.ts`：支持就地极速添加今日任务 actions。
- **数据库与 API 影响**：
  - 0 破坏性，0 后端 SQL 迁移，完全复用现有的 `time_management_tasks` 与 `save_time_management_task_v2` RPC。
